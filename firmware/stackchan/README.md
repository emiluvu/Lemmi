# Emilia’s firmware boundary

No firmware or hardware capability is implemented by this starter. Use the shared v1 schemas in `packages/contracts/src/device.ts` and the fake client in `scripts/fake-device.ts` as transport examples only.

Start with installed-toolchain inventory, immediate local Stop/mute/indicators, then the combined display/touch/Wi-Fi/camera and sequential audio experiment. Negotiate measured audio/frame limits with Anay before extending the schema. Camera authorization/local consent/expiry must pass before petting/motion polish. Browser or fake-device checks never establish local hardware behavior.

The gateway is loopback mock-only with one shared session. Its development credential is not pairing, TLS, caregiver authorization or a deployable device configuration. Do not adapt that credential or `ws://` transport for real K151 deployment. Anay must supply scoped pairing and validated WSS first.
