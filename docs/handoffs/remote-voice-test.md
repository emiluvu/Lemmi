# Remote browser voice rehearsal

Use fictional team data only. You can test from another machine; no SSH tunnel or localhost callback is needed for this participant flow. Current runtime and deployment acceptance are recorded in [backend status](../backend-status.md). Public voice and the frontend/Teach build are deployed in runtime `f5724a0`.

The public synthetic local-STT → actual-OpenRouter → local-TTS test passed with simulated consumption receipts. An actual browser microphone, audible speaker, human recognition quality and K151 controls have **not** been verified by that test.

1. Open [Lemmi access](https://lemmi.chaoswarrior.dev/access) over HTTPS. Enter the shared outer access key obtained privately from Anay. Do not paste keys or callback URLs into chat/issues.
2. Open [Participant](https://lemmi.chaoswarrior.dev/participant). Create a clearly named **fictional** test profile, then select it. If already assigned to another profile, use **Change participant** first. Creation does not copy Alex's biography or interests. Use a separate browser profile/context for each independent endpoint; multiple tabs share one endpoint cookie and can conflict.
3. Press **Start conversation**. Confirm this browser is the active endpoint. If another endpoint owns this profile, coordinate with its tester before **Use this browser**, then press **Resume to ready**. Handoff cancels old work and stays paused until Resume.
4. If muted, choose **Unmute (capture stays off)**. Unmute alone must not start recording. Press **Speak now**, allow microphone permission for this HTTPS origin, and wait for the visible listening notice.
5. Say one short fictional English sentence, such as “I would like to talk about gardens.” Press **Finish speaking**. Capture must stop; wait for the response before speaking again. The capture window is bounded to about twenty seconds. Check both the displayed reply and actual audible playback. No microphone capture may overlap speech playback.
6. Test **Pause** during capture and again during playback: local capture/output should stop immediately. **Resume to ready** must remain capture-off; another **Speak now** is required. Test **Stop** during a turn: it should end the session and suppress late output. A new explicit Start is needed afterward. Muting must cancel capture; it has a different scope from Pause/Stop.
7. Test handoff using a separately enrolled endpoint for the **same** fictional profile: old capture/output stops, the new owner sees a paused session, and explicit Resume does not start capture. A distinct fictional profile must remain unaffected. Backgrounding the browser pauses locally; reconnect never resumes listening automatically.
8. If access expires, unlock `/access` again. Browser endpoint enrollment lasts thirty days; an expired/revoked enrollment requires explicit release/re-enrollment using **Change participant**, then selecting the profile. **Reconnect** retries the existing assignment and does not renew an expired key. Existing indefinite legacy robot keys remain valid until revoked; do not rotate the shared team key to fix a browser test.

Teach Lemmi is available only after the frontend/Teach deployment and when the gateway advertises it. Use the offered reviewed topic, **Different topic**, **Not sure**, and **Finish teaching**. A new empty-context profile may correctly have no eligible teaching topic; this is not permission to borrow Alex's context. Feedback is session-only, and teaching is not a memory test or a durable biography update.

If a step fails, record the browser/OS, step, visible session state, whether the listening indicator stopped, and the sanitized error text. Report permission denial, missing audio negotiation, duplicate-identity conflicts, disabled service and provider failures explicitly. Do not attach raw audio, transcripts, secrets, private headers or full callback URLs. A successful rehearsal still leaves physical Stackchan capture/playback, independent Stop/mute/watchdog and firmware key storage to Emilia's hardware checks.
