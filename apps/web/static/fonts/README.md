# Lemmi typography

Nunito variable font, weight range 200–900, served locally as `Lemmi Sans`.

- Source: Google Fonts, `google/fonts/ofl/nunito/Nunito[wght].ttf`.
- Downloaded November 14, 2026 from the official Google Fonts GitHub repository.
- License: SIL Open Font License 1.1, included in `OFL.txt` with its original copyright notices.
- Runtime font loading stays on the app's own origin; no Google Fonts request is made by the browser.
- CSS uses `font-display: swap` and a rounded/system fallback.

The filename is project-local; the original font bytes are unmodified.
